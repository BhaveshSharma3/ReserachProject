# SISO, SIMO and MIMO BER Simulations

MATLAB simulations of BER vs SNR for BPSK over Rayleigh fading channels, using the model y = Hx + n.

- **SISO (1×1):** baseline single-antenna link
- **SIMO (1×N):** receive diversity with Maximal Ratio Combining
- **MIMO (Nt×Nr):** spatial multiplexing with Zero-Forcing detection

These were my starting codes for my M.Tech research at IIT Mandi on low-complexity detection for XL-MIMO systems. Run any script in MATLAB to generate its BER plot.
